# Photomatón Mailen

Photomatón casero con Raspberry Pi 5, pantalla táctil de 3,5" y webcam, controlable desde el móvil **por Bluetooth y sin internet**.

- **Webapp de control:** https://mibaldi.github.io/photomaton-mailen/ (Chrome en Android → Conectar → Hacer foto / Estado / Reiniciar / Apagar). Ficheros: `index.html`, `sw.js`, `manifest.json`.
- **[Guía para montar la Raspberry Pi](raspberry/README.md)**: sistema, pantalla, photobooth-app, cámara, mandos Bluetooth, servidor BLE, flash y sonido, apagado seguro, Telegram y Drive.
- **[Piezas impresas en 3D y decoración](impresion-3d/README.md)**: caja, funda del mando, palitos, clip, marco y pegatinas.
